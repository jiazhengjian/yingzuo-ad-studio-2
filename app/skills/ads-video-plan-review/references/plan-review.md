# 最终方案综合审核

审核分镜协调后、程序已排时的实际最终方案：最终 `ad_script`、有序镜头和状态、完整台词及其窗口、执行窗口、生成段、已选制作约定和商品证据。初稿、原先估计与作者意图只作对照，不沿用旧结论。

对照原始要求和已选方向的结构、核心画面、产品记忆、声音任务及必要支撑信息。用途环境不等于指定片场；历史缺字段不追补，未选候选不补齐本片，可选资料不升级为必讲清单。共同创作方法用于判断表达，不把其中所有审美建议都变成阻断条件。

## 先确定问题的性质

**必须阻断**：商品事实错误或无依据主张；违背用户明确要求、已选核心或制作约定；实际旁白代念制作、策划指令而没有交付所需话语；明确物理矛盾、必要动作缺失或实际时间不足；必要声画关系、说话者身份或语句完整性不成立。定位实际原句、镜头或窗口，说明哪项必要条件受到影响。

**改进建议**：意思已清楚且必要信息完整，但措辞普通、不够自然、审美或节奏平淡、重复展示的收益有限；上层概括可由明确的实际分镜消歧；作者自行添加的可选停顿未兑现。放入 `suggestions`，不能因此把已有内容、执行、镜头或声音硬检查置为失败，也不以这类建议触发必须返修的结论。

**类型贴合也是建议。** 本轮若注入了该类型 playbook，把开场钩子、节拍形状、台词密度、景别与切节奏、产品出镜比例这些偏差写入 `suggestions`，`kind` 用 `type_fit`，并引用实际台词、画面或运镜原文。产品片和口播可以建议英雄定格。剧情末镜应是插入的近景或特写：第一帧产品就已经在故事里它该在的位置，机位锁死，不再推近；只带一个小动静，例如火苗、切第一刀的手、热气、人的一角或画外笑声。前一镜若是人物动作，这一镜应硬切。写成推近、或同一镜又有人物动作又在改变景别，只作建议，程序会改视频提示，不要因此让 `ready=false`。剧情末镜若写成英雄定格、把家用物品带出门、末句在点题、对白在说卖点、卖点没有高光证明镜、状态结果还停在半程、或床入画却没有背景人物、或没写翻身却面向镜头，由程序硬失败。只是用「床上的人」「仍在睡」接着写、没把朝向再写一遍时，程序会补上，不算失败。审核不要把这些改成通过。不得因此把六项 `checks` 打成失败，也不得让 `ready=false`。事实错误、已确认要求、动作装不下和声画不成立仍然阻断。

**镜头工艺由程序附加。** `shot_craft` 覆盖出镜比例、画面里的比喻、缺景别或运镜、结尾定格，以及过于均匀的切点。模型不必重复这些项，也不能因此判失败或再开返修。

**台词是否对焦商品、前后连贯也是建议。** 写入 `suggestions`，`kind` 用 `line_focus`，引用实际台词原文。人物讲解的卖点要有主语，并用而且、还、另外、所以或关键是接上。产品片不必有主语，不要描述镜头，不要编画面上没有的人。句数按类型 playbook，不在这里另定。剧情不套口播主语，不念画面，好处落在动作结果上。每一句要推进故事，或者说出画面没法看见的事。只把画面上的动作念出来的，删掉，让动作自己演。例如「再进一点点。」写入 `suggestions`，不要因此让 `ready=false`。已经按声音方向写成内心独白时，不要因此让 `ready=false`。剧情还要核对台词和动作有没有推翻前面的镜头：谁已经知道什么、人是什么时候到的。例如前一镜说先别进来，后一镜又问你什么时候来的，写入 `suggestions`，不要因此让 `ready=false`。不得因此把六项 `checks` 打成失败，也不得让 `ready=false`。程序会先改一次台词；产品片连着五句以上会先改写，改完仍在，就只留这条建议。

判断可选性须有依据。停顿若来自用户明确要求、已选核心，或是理解必要信息、辨认对象、完成动作所必需，仍按硬条件检查。不能确认真实必要要求是否满足、关键事实是否有依据、动作是否可执行时，说明缺口并保持失败；不能改称“建议”或自行假设成立。普通措辞不足与必要意思缺失分开判断，不能用“自然度只是建议”放过制作指令、错义或漏掉关键内容。

## 实际内容与表达

按共同加载的 [分类脚本与声音表达](../../shared/script-expression.md)，先读实际原句和有序镜头，再核对意图。`purpose`、摘要和事实 ID 不替代交付物。

1. 逐项检查台词与画面中的商品主张，区分已确认事实、图片可见外观和虚构情境。未知口味、功效、材质、规格、促销或真实体验不能由表演、道具和视觉隐喻暗示。引用来源必须支持当前表述的条件与程度。
2. 检查已选开场、核心展开和结尾是否兑现，产品是否参与受众的选择、用途、审美或互动。产品展示可由形态、光影、构图推进；已完成局部线索、完整轮廓与收束，不再强加功能演示或人物故事。明确遗漏已选核心、产品作用或必要商品信息时，按对应内容项失败；已有推进但比较普通、角度重复或情绪不够强，列具体建议，不因此判 `narrative_progression` 或受众关联失败。

冷启动观众只看第一镜画面、只听第一句，要能说出这是什么商品、在什么场合。第一句听不懂，或人物讲解的第一镜没有商品，写成建议并引用第一句和第一镜原文。剧情和产品片允许开场先给处境或气氛，但前大约 3 秒要看见商品或用法。这些由程序自动改一稿；改完仍在，就记建议，不要只因这一项把 `ready` 判成 false。
3. 连读实际台词，再逐句与当时画面对照。直接把“镜头拉远”“旁白介绍卖点”等制作指令读给观众，或台词无法传达本段必要意思，不能通过 `natural_speech`。能明确传意、只是不够有吸引力或有惯用措辞，列建议。`audiovisual_complement` 检查必要理解、人物关系和信息是否共同成立；保留教学、揭示、强调与反差等有效同述。看得见的内容可以说，冗余但未破坏必要表达时建议精简；声音说出的对象、状态或含义与当时画面实质冲突，或关键信息两者都未交付，仍须失败。静默可成立，不要求每镜一句或一个新卖点。所有问题定位实际台词或镜头，不用作者自称“强调”证明成立。

## 动作、状态与人物

按镜头顺序检查 `start_state`、实际描述、`allowed_changes`、`end_state` 及镜间接续。追踪人物、商品、道具、部件的持有人、位置、依附关系和余量：取走、转交、拆开、消耗后，状态必须改变；不能凭空复原、重新连接或同时占据矛盾位置。未分离的附属物随主体移动；分离须有去向。不能为填状态编造未知数量或规格。

附着头发、手或后脑属于人物局部，须与角色约定相符；独立发束或假发须在实际画面明确，不能猜测含糊“发丝”的载体，也不能把不露脸当无人。核对 `production`、角色 ID、唯一说话人、场景与声音形式，不能由分镜自行改约定。

完整动作按必要准备、操作、完成和反应追踪，不能把不相容的动作全部并行。区分入镜前已省略、本镜实际发生、离镜后才省略的过程。`cut` 或 `scene_change` 只支持其所在切点的时间推进，不能证明镜内新开始的动作已完成；`continuous` 或另建一条镜头记录不构成时间省略。未拍完时末态只能到实际完成处，下一真实切点及可理解起态才可承接稍后状态。“按完成记录”“不展示后续”等自述不证明操作或消耗已结束。

首镜可直接从商品已摆好、人物已坐下的起态开始，不要求拍前史；作者写“省略入场”不因 opening 缺前一切点而失败。首镜内部仍须可执行。动作终点不扩大：“已入口”不等于“已吞咽”；只到入口且下一真实切点后才是稍后状态，不额外加入吞咽任务。末态明确已吞咽、已吃完或需要空口说话，则须有相应过程和时间。

逐镜判断 `temporal_omission`：未跳过必要过程为 `no_omission`；省略有位置正确的真实相邻切点、切前终态及切后起态支持为 `supported_by_cut`；省略位置错误、连续跳到完成态或仅凭自述完成为 `unsupported`；必要过程或端点无法确定为 `unclear`。后两者使对应镜头失败，不能当作审美建议。`transition_boundaries` 仅定位真实前后镜与切点，不证明动作完成。

仅 `supported_by_cut` 提供 `temporal_omission_evidence`：定位 entry/exit，指出省略动作，并从切前、切后相邻镜头的 `description` 逐字摘录支持状态的原句。远处镜头、作者目的或“已完成”的自评不能代替。引文只帮助核对，仍须判断是否真的支持省略；普通 `no_omission` 不补这个对象，缺依据不凑引文。

### 用详细执行消歧，不替缺失过程补戏

联合核对本稿 `timing.action_plan`、`time_transition` 与实际镜头描述、摄影机运动、起末状态和接续。商品静止而摄影机换角度，不需要省略商品转动，应为 `no_omission`。上层“从正面到侧面”可表示观察角度变化；若详细镜头已明确商品静止、机位如何移动且前后状态相容，不把这种概括强解为商品自身转动。硬项通过，措辞可列建议。

消歧不能改变明确动作。若一处明确要求商品自身旋转、人物已操作或省略某必要动作，另一处却明确同一时段未发生，并且不是观察角度的概括，则是实际执行冲突，`execution_check.state_continuity` 失败，引用相互矛盾的 beat 与 shot 原句。不能静默删掉动作或凭建议放行。

每镜的 `visual_execution` 联合阅读实际描述、`camera_move`、状态和接续。画面如何形成已经明确可行，或一处概括能由其他明确描述消歧，为 `clear`；逐字引用描述或运镜关键句，说明相互印证关系。不同术语不自动构成冲突。

`conflict` 必须指出同一时段不能同时成立的两个实际画面关系。若稿中仍不足以确定画面如何形成，须由审核人新增分屏、剪辑、人物、物体变化或新状态才能成立，判 `unclear`。这两种情况使对应镜头与状态执行失败。分屏、叠化、切镜、连续机位变化都可成立，但必须已有相容实现；“不同视图并置”不能被猜成普通斜侧视角。终态、摘要与目的不证明未描述的过程发生。摄影变化不清楚也不自动等于主体动作被省略，二者分别检查。

### 说话者与声音形式

按已选 `speech_mode`、`speech_delivery` 和 `speech_requirements` 逐句检查，不因分镜写“画外说”就改变声音模式。画外音无需人物张嘴；无人声不能有台词；角色不能替别的角色说话。声音一致性只是计划要求，不冒充实测声纹。

`speaker_visibility` 按实际说话窗口判断：完整可见正确角色开口为 `visible_speaking`，不显示开口为 `off_screen`，无法判断为 `unclear`，已确认画外音为 `not_applicable`。未指定延续方式或 `visible_only` 只接受可见开口，手部、商品特写或角色 ID 不是开口证据。

明确 `on_and_off_screen` 时，逐句 `shot_visibility` 必须覆盖说话窗口内全部相交镜头，并给出逐镜实际依据；同时存在可见开口与画外延续时总标签为 `mixed`。任何镜头不明仍不通过，不靠总标签掩盖。全片须建立实际可见开口的同一说话人；全画外不能冒充人物讲解，镜内出画时点不明也不能猜为通过。这些均是文字计划检查。

人物讲解或 `character_dialogue`：第一句台词所在的镜头要有说话人，并且 `speaker_visibility` 为 `visible_speaking`。这一句最好在她的脸已经入画之后大约 0.5 秒内开口。做不到时写成建议并引用该句和该镜，由程序自动改一稿。改完仍在，不要只因这一项把 `ready` 判成 false。

结尾最后约 2 秒应停住。商家指定了去向时，结尾要说出那个去向；没指定时不要另加去哪里的话。不够 2 秒或还在放下商品，写成建议。缺了指定去向由程序补上，不因此判失败。

## 实际时轴与声画

逐句及关键短语核对原句、窗口、对象、含义与当时动作。后面才出现的状态不能支持前面已经说出的完成结论。一句可以跨相关镜头，一镜可承接相邻内容；不能只看镜头 ID 重叠。可靠但不可拍出的参数可由台词表达，画面不能伪造实测；审美或情境话语无需逐字图解。

独立估计实际必要动作、可并行部分和辨认时间，与程序给出的合法执行窗口比较。`speech_overlap=true` 使用本拍实际窗口与对应镜头的交集；`visual_seconds` 是作者估计，`visual_end` 不是并行动作硬截止。仍须判断能否并行，入口、吞咽、开口等不相容动作不能靠标签消除。`speech_overlap=false` 须先在视觉窗口完成动作，再使用讲话窗口，不能借之后或相邻内容的时间。多内容覆盖同镜时逐段核对，不能照抄作者估时、隐藏必要动作或默认快放。只改估计或说明但实际动作与完成态未变时，仍按完整动作评估。必要时间确实超过可用窗口，动作容量和总体结果必须失败。

只估实际必要任务，不给可选审美停顿追加硬时间。比如作者写了片尾安静停留、实际台词到片尾才结束：若不涉及明确要求、核心落点或必要辨认，记录未兑现停留的建议，不能单凭它判容量失败；若它是必要条件则仍核对真实空余时窗。不能以此忽略真正动作未完成、语句被截断或关键信息来不及表达。

切镜或连续观察若破坏必要行动与信息接续，须拦截；仅节奏单一、随句切镜或重复扫视收益有限，列建议，不令 `cut_necessity_passed` 失败。`opening` 和 `continuous` 不算硬切。合法声音留白不是错位，声音边界无需与画面切点重合。

核对生成段边界、完整语句与不可拆动作、背景声音接续，以及参数和素材是否在实际能力内。结构覆盖和引用通过后仍须核对语义；单请求不保证成片流畅。

## 结论与修订交接

按本轮 Schema 返回完整内容、执行和声画检查，以及独立建议；字段和政策版本由程序合同定义。失败项必须有实际证据、位置、受影响的必要条件和最小修改范围；通过项可省略重复说明，逐镜摄影依据仍保留。有任何硬项失败，整体不能通过；仅有建议且必需项均成立时可以通过，不能为表达“还可更好”而置硬项失败。

一次汇总所有可确认问题，不因发现第一项就省略其他检查。缺必要信息时说明无法判断的内容，不能猜成功。审核不改稿、不改判例来凑通过，也不填写程序负责的版本哈希。建议不是修订指令，不自行增加调用、角色或确认步骤。

程序管理有限返修与预算。必要修订仍保留事实、已选核心、用户固定内容、声音制作约定和片长，只改失败相关内容与必要相邻状态；不把未固定的初稿台词或旧秒点当锁定要求。修后完整重审，因为相邻状态与时窗可能受影响；建议未采纳不升级为新阻断，实际硬问题未解决也不能降级为建议。以上仅判断文字方案可否采用，不声称已验证真实媒体效果。
