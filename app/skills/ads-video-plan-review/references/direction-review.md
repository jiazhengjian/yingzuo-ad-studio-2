# 方向审核

本模式共用 [商品依据与创意边界](../../shared/product-evidence.md) 和 [广告形式与创意交接](../../shared/ad-form-contract.md)。读取原始要求、实际原图、`immutable_brief`、三个候选及能力输入；冻结保护来源，不自动证明作者观察与意图解释正确。

## 按实际内容判断

先从拟议画面和声音判断观众能接收什么，再对照标题、`angle` 与主张。不能用目的说明或事实 ID 反向解释任何画面；简短 `note` 引用实际内容能传达的产品认识，或指出具体缺口。

| 检查 | 判断对象 |
| --- | --- |
| `claim_support_passed` | 方向全部文字、视觉暗示和制作约束中的主张是否得到来源支持；修订后不新增外观到功能的推断 |
| `product_role_passed` | 对照原始用户要求，逐条确认该候选独立覆盖本轮必需内容，同时检查主推特点、受众意义和实际呈现是否相连；采用共享参考的必需/可选区分，不能靠另一候选补齐或以主次为由删掉必需内容 |
| `expression_form_passed` | 实际内容是否由用户所选主要方式承担，制作安排是否一致，类型标签不能代替内容 |
| `film_concept_passed` | 原始要求与创作意图是否相符，结构、核心画面及变化、产品认识、记忆点与声音任务是否对应；不可修正的意图误判应失败 |
| `attraction_passed` | 具体观看期待能否从实际内容得到回应，是否指向产品；不强制人物冲突，也不接受空泛好奇自述 |
| `creative_tension` / `hook_strength` | 只记 low、medium 或 high：观众处境有没有让人想看下去，开场钩子是否具体且后面有兑现。低分不把 `ready` 改成 false |
| `distinct_directions_passed` | 三项的创意机制、开场钩子、品牌世界路径和观看过程是否实质不同；可共享已确认卖点，只换功能名或微距不自动产生差异 |

依据实际画面检查物理/动作合理性：起态、动作顺序、物体依附、余量和终态须一致；必要过程可明确省略，不能借省略补造效果。按实际动作与必要观看判断本轮时长能否容纳，不推迟到完整分镜才处理明显过载。

需求覆盖直接核对 `merchant_request`、`conversation` 与原始澄清问题和回答，不能只检查作者已筛选的 `angle` 或 brief。`note` 简要指出必需内容的实际呈现及修正；缺失时在同次回复内补足并协调声音与制作安排，不把补词放在 `reason` 或 `production_notes` 就算完成。无法在来源与用户约束内修好时 `product_role_passed=false`，不可仍设 `ready=true`；推荐项没有豁免。不新增审核项、调用或问卷。

## 同次修订的权限

在这一回复内修好尚未确认的候选，再对实际修订稿判断；不只改审核说明，也不追加模型阶段、媒体或确认。保留方向 ID、rule_id、顺序、`hook_type`、`brand_world`、`consumer_insight`、`big_idea`、`label`、商家事实与用户明确要求。只改没有事实支撑的商品主张，可改 `hook`、`payoff`、`key_visual` 和 `evidence_ids`。schema 里没有的历史长文不要新写；若审前方向里已经有，留在原处。改不掉时把 `claim_support_passed` 设为 false，不要把创意改成更平的说明书。情绪、场景、夸张和幽默可以留下。遵守本轮参考容量。

图片观察含推断时，可返回 `image_observation_corrections=[{"fact_id":"原事实ID","text":"原图支持的观察"}]`，无需纠正时为空。只修改已有 `source_kind=image` 的文字，不增删事实、不改 ID 或来源；其余 brief 冻结。保留可靠可见部分，同步清理三个候选及商品约束中的旧断言。无法在此权限内处理的来源或意图错误如实不通过。

`brief.assumptions` 的作者初稿设想不是用户硬要求。用户未固定声音时，可将候选无人声改为简短旁白来补足实际信息；审后 `production`、`film_concept` 决定实际声音与人物，旧 none 假设不能阻止修订。人物讲解保留唯一说话人且须有实际可见开口，只有明确采用 `on_and_off_screen` 才可让同一声音延续到商品特写，不能改成全片画外音蒙太奇冒充讲解。全片只见手、后脑或附着发丝时仍须登记局部出镜角色；独立发束/假发须明确载体，与人数、appearance及声音安排一起核对。

## 输出

交付完整修订候选、图片观察纠正与全部检查，结论基于纠正后的事实和本次实际内容。必需检查全部通过才 `ready=true`，未解决问题保留具体原因；不写完整脚本、分镜或媒体提示词，不声称实际成片已通过。
