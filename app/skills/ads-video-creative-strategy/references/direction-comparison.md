# 方向比较方法

这是一套创作比较方法，不替代消费者研究或投放结果。共同的事实与形式边界由本阶段共享参考维护。

## 先读实际内容

暂不借助标题、`angle` 和“让观众记住某功能”的目的说明，只看拟议画面与声音能传递什么，再对照主推特点。商品有这项功能，不等于任何画面都表达了它；视觉含义不足时补信息或改概念，不用解释性字段自证。

| 比较项 | 应当成立 |
| --- | --- |
| 需求覆盖与产品认识 | 逐条候选对照本轮原始要求，必需内容分别在何处被看见或听懂；`angle` 可有重心，但不能据此删除其他必需内容，商品出现或泛用称赞不能代替 |
| 创意展开 | 开场、展开与落点形成同一条可想象的广告，具体观看期待得到回应 |
| 视觉或表达机制 | 核心变化、信息组织、商品参与的行动或观看关系具体可读 |
| 方向差异 | 去掉标题仍有不同的画面骨架、贯穿母题或侧面证明，以及不同的创意机制、开场钩子和观看过程。同一背景只换口号不算分开。不要三条都是平铺的真场景演示 |
| 制作容量 | 核心动作与必要观看在本轮时长、角色和参考容量内成立 |

先确认每条独立覆盖共同要求，再比较创意差异。共享同一组必要信息和可靠卖点可以。没有锁定结构的产品片不能三条同一结构。锁定为一种结构时，母题或侧面证明必须分开。有已知好处时，每条都按生活问题、一小段产品世界可视化、真实结果、产品定格来组织，而不是换成真实房间里的使用演示。方向卡用大白话写出差别，剧情三条的故事核不能是同一个处境换说法。只把功能分给不同候选不能替代创意差异。商品替换检查用于发现没有商品作用的空泛内容，不要求这一创意只能适用于本品或证明独家优势。

## 两个已验证的判断边界

- 同样的风托发丝、局部特写、落下收束，改成微距或换写风速/护发标题仍是同一机制；应重新组织其中一个概念。这是判重反例，不是吹风机方向模板。
- 冷暖光可以建立温度意象，却不一定让观众知道产品具备温度控制；可让短旁白补充已知功能。纯产品不必无人声，也不把旁白变成可见动作解说。

按上述检查交付修正后的概念与简短可核对依据，不展示内部推理，不承诺推荐方向已经证明有效。
