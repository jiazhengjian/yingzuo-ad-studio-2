# Ads Video Script Planning

读取商品事实、用户明确要求、已选方向、受众、目标时长、实际画面、声音身份与 `production`。按共同加载的 [分类脚本与声音表达](../shared/script-expression.md) 区分事实、固定原句、创意含义和作者解释。若 shared_references 有本类型 playbook，开场、节拍、台词密度、收束，以及台词是否对焦商品、前后是否连贯，都按那一份写。人物讲解的卖点要有主语；只有这种片子在资料短时才补具体场合和体感。剧情是短对白，不念画面，好处落在动作结果上。台词沿痛处、对应的解决、结果这一条往下走，这一条主要给人物讲解。一个卖点说一次。不编数字或规格。保留所选方向的核心与必要商品信息；选中概要不等于锁定其措辞或逐项镜头表。

谁开口、画外还是内心独白，沿方向里已经写好的声音形式，不在这里另定。

本 Skill 同时组织内容稿和实际话语。当前格式决定本次职责：

- 完整内容稿：使用 [完整内容稿与动作容量](references/timed-script.md)，同时交接动作状态与联合容量，并按 [时长与留白](references/speech-timing.md)、[跨镜声画关系](references/speech-picture-alignment.md) 和 [广告台词示例](references/ad-dialogue-examples.md) 写能说的句子。
- 分镜协调和窄台词重写：只使用本文件与台词示例，不加载整份时长参考。

## 台词

1. 从实际内容确定听者此刻需要理解的意思。产品主张、操作解释、审美邀请和人物回应各有用途，不把每一种话语都写成卖点介绍。说话人沿已选 `production`。
2. 直接写入 `narration`：以说话者面对听者的方式表达具体内容，不代念策划目的。保留事实原有条件与用户固定原句；其余草稿可重新成句。先让实际句子成立，仅在本轮 Schema 要求时概括其目的。用 [广告台词示例](references/ad-dialogue-examples.md) 里的「说出口的对照」写能说的句子。口播卖点要有主语，并用而且或所以接上，可以连着说多个卖点。只有人物讲解在资料只有几个词时，才用具体场合和体感说开。产品片不要复述镜头。说人话，整条一个主好处，画面也不另演示第二个卖点。大约 30 秒可以再加一个配角好处，分清主次。45 秒以上可以再展开，仍然不要并列清单。不要文案腔，不描述镜头，不编画面上没有的人，不用痛点问句开场，不把时长说满。可以有不说话的画面证明，不规定那一拍占几秒。剧情是戏里的第一人称短对白，不念画面，也不把这一镜已经看见的事再说一遍，不要把第三人称解说塞进人物嘴里，好处用看见结果后的反应。问句的下一句回答同一个问题。一个卖点说完整再换下一个。不编数字或规格。对照是方法，不是当前商品的事实，不能整句搬。
3. 单独连读全部台词，检查对象、指代、词语搭配和前后衔接。短促的广告句、随口对白或面向观众的讲解都可以成立，不为填满时长加空话。再与画面合看，按共同参考保留有作用的强调、教学和反差；该安静时留空。
4. 完整内容稿按本轮声音约定、时长与留白及跨镜声画关系核对整句、动作和停顿的联合容量；分镜阶段按其动作与时间合同继续协调。必要时重写未固定话语或内容，不截半句、不假定加速。Schema 要求的表演意图说明听者、语气和停顿，最终秒点由程序安排。

## 输出与交接

按本轮 Schema 返回实际内容与台词，话语可以跨相邻镜头，不按每个切镜另起一句。分镜继续协调未固定内容，`plan_review` 独立审核实际声画；无需单独的文案分析稿或额外调用。不增加分析稿、额外调用或前置确认。

## 自检与失败处理

- 实际句子承担既定任务才算完成，只修改 `purpose` 或 `message` 不算改好台词。
- 沿 `production.speech_mode`、`speaker_id` 和 `speech_requirements` 保持声音身份与可见性。单一说话人不增加应答者，无人声保持空台词；不假称真实试用经历。
- 尚未生成音频，字数与时长只是预算，不能擅自切换配音路线。
- `task_kind=line_jargon_rewrite` 时只重写列出的句子。按 `line_style` 说出口，承接 `big_idea` 的意思，不照抄策划词。只用该句和 `facts` 里已有的信息。每句不超过该句 `max_characters`。
