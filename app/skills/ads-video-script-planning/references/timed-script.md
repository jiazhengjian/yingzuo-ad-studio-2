# 完整内容稿与动作容量

## 输入与前置条件

读取商品事实、已选方向、受众/场景、目标时长、`production` 与运行时容量。按共同加载的 [分类脚本与声音表达](../shared/script-expression.md) 区分事实、用户固定内容、创意含义和作者解释。这里写可由分镜协调的内部初稿，不把它标为审定稿，也不重开方向选择。

`story_summary` 与 `attraction_mechanism` 交接核心和观看期待；有 `film_concept` 时保留其结构、核心画面、记忆点和声音任务。结合 `brief.creative_intent` 区分用途环境与明确片场，不因职业或字段含 story 就给纯产品概念添加剧情。历史方向缺少新字段时沿原开场、推进与收束，不补造已选概念。重点与 `product_expression` 承接的必要支撑信息一起展开，允许调整声画分工，不遗漏用户要求或从未选方向补内容。

## 执行

共同参考负责三类广告的推进与声画判断，Dialogue Writing 负责实际话语；本 Skill 组织内容和联合容量。同次成稿，不新增创作调用或前置审核。

1. 沿已选概念组织实际观看过程：什么先被看见、随后展开什么、最后留下什么。用 `beats` 承载必要信息或行动，不固定段落数、幕次或每段新卖点。过长时保留关键时刻，不逐项实时展开概要里的附加动作。
2. 每段先写 `visual_role` 与实际 `narration`，空台词也可承载完整观看任务。与 Dialogue Writing 同次让句子成立；再用 `purpose`、`message` 概括其作用和声画关系，最后由整稿概括 `core_message`、`audience_takeaway`、`product_role`。这些解释不增加一句观众原本没听见的意思。
3. 结合实际动作与说话填写 `timing`。相邻内容承接同一对象、状态或观点；必要省略交代前后状态，持续动作保留连续性组。内容段落不是切镜点，一段话或持续画面可以跨镜；生成请求边界仍由程序决定。
4. 连看画面、连读台词，检查开场期待、必要商品信息和结尾是否共同成立。保持选定角色与声音身份；只有一个说话人时不替另一角色加应答，无人声时全部台词为空。必要停顿用于观看或行动，不靠重复部位和空泛感慨填时长。

## 输出与交接

按本轮 Schema 输出内容稿，每段保留事实引用。`visual_role` 说明实际看见什么及其变化；具体景别、镜头数与切点交给分镜，不为凑时长伪造可拆边界。

每段 `timing` 是计划估计，不是实测：

- `visual_seconds` 包含完成动作、辨认对象和必要停留所需时间；`action_plan` 简述动作先后及可同时发生的部分，不能把顺序动作全部算作并行。这里只计算视觉所需时间，整句说话时长由程序另算，不重复计入。
- `speech_overlap=true` 仅用于画面动作与说话能自然同时发生的段落，最低占用取视觉时间与说话估计的较大值；否则为 `false`，先留视觉时间，再留完整台词时间，两者相加。吃入口、吞咽后才说话等场面不能假设全程重叠；需要部分重叠时按内容合理拆段，不因此新增镜头。
- `start_state`、`end_state` 说明人物、商品和道具的关键状态，包括物体归属、部件依附与消耗后的剩余。附属物随主体移动；只有明确的分离动作才改变依附，已取走或消耗的部分不能留在原位或随后复原。`time_transition=continuous` 表示与上段连续，`ellipsis` 表示省略了一段过程，并在动作计划中交代。省略发生在本段开始与上段结束之间；先明确省略后已处于什么状态，再写本段动作，不能在本段连续动作中突然跳过过程。省略能保留故事落点，但不能伪造已知规格、效果或消耗量。

`boundary_before` 与 `timing.time_transition` 是不同字段：前者用 `continuous`、`complete`、`scene_change` 表示内容段落前的接续或可拆边界，后者只用 `continuous`、`ellipsis` 表示故事时间是否省略；不能把 `ellipsis` 填进 `boundary_before`，也不能把完整动作边界当作时间省略。

先估计全片动作与语音联合预算能否容纳，再交分镜；字符预算只估计声音容量。较长过程可用关键动作和清楚的时间省略连接收束；连续画面里不能凭空改变余量。无法容纳时先删重复、缩短次要过程或明确省略，保留故事核心和用户固定内容，不能留给分镜硬挤。

内容稿交给 `storyboard` 协调未固定台词、动作、段落与估时；程序编排最终时轴后，由 `plan_review` 独立审核实际方案。不要增加前置审核或额外分析稿。

## 自检与失败处理

- 核对实际句子与画面，目的说明、事实 ID 和字段齐全不证明表达成立。商品一致性是制作约束，不是消费者选择理由。
- 视觉概念、人物行动和情境可以创作，不能借其新增未知口味、性能、价格或真实试用经历。压缩时保留核心依据与固定内容，不悄悄加长用户时长。
