# 历史固定时轴分镜

仅供 `legacy_storyboard` 兼容调用，包含旧 storyboard 及有限 storyboard_repair 的资源。以本轮旧 Plan Schema、`approved_ad_script` 与 `expression_schedule` 为准；不要输出新 DirectorDraft，也不要执行 plan_refinement 的可改稿规则。

## 编排与输出

1. 读取选中方向、已审脚本及 `timing`、原句台词、商品事实/原图、确认情境、给定内容/说话窗口和能力限制。图片已生成时还应看实际内容；计划文字不证明图片符合要求。
2. 保持统一商品锚点、空间、光线、色彩、摄影与声音气质。地点、角色和声音形式服从已选制作决定，不为构图方便改变环境或新增说话人。
3. 按动作、观察重点与节奏安排镜头，再标明覆盖的内容。一镜可用 `beat_ids` 承接相邻多段，`beat_id` 为首项；一段也可由相邻多镜完成。完整台词逐字保留给定窗口，整句可以跨相关镜头，不因切镜拆句或移动窗口。
4. 描述实际对象、构图、动作先后、摄影和可见状态。同一长镜中某句话须等对象出现或动作完成后才成立时，说明该窗口内的实际动作进展；只把同镜 ID 关联多句不足以证明对应。
5. 核对每镜起态、描述、允许变化及终态，追踪人物持物、商品/道具位置、部件依附与消耗余量。前置动作不能重复执行而保留相同余量；移除、分离、转交与消耗必须持续反映到后续镜头。未知份量或性能仍未知。
6. 按脚本 `time_transition` 落实真实时间省略与明确切点；连续长镜不能突然消失、复原或跳过必要过程。景别切换须保持可理解的关系，不用“丝滑转场”替代接续说明。
7. 对照给定执行窗口估计动作、辨认和停留。`speech_overlap=false` 的前置动作须在该段开口前完成；同一人操作、入口、吞咽和发声的冲突不能凭窗口重叠消失。镜头合并不产生额外时间，不能隐藏必要动作或假定快放。
8. 人物对白须在给定窗口看清指定角色说话，商品/手部特写不能宣称支持口型；画外音不要求张嘴，无人声不增台词。声音、环境声与音乐分别交代，声音一致只是要求，不能声称已试听。

按旧 Schema 输出 `segments`、镜头 ID/起止时间、相邻内容引用、描述、事实引用和连续状态，以及完整 `speech_spans` 和短语 anchors。覆盖给定总时长与内容窗口；声音边界无需等于镜头边界，整句与给定窗口不变。`entry_transition=continuous` 可由程序继承前镜 `end_state`；显式起态仍须相容，其他转场须完整起态。引用原图、场景与角色素材，不增加逐镜生图。

## 历史返修边界

- 收到 `draft_storyboard`、审核或结构反馈时，按本轮旧合同修正原分镜，保留脚本、完整台词、说话窗口、固定要求、制作决定、总时长与生成分组。可调整构图、切点、短语关联及非必要附加动作，不通过改 purpose 或自评宣称解决问题。
- 必要动作与声音合计仍超出容量时，具体说明脚本容量冲突，由旧程序既有路径处理；本兼容分镜不能自行修改已审脚本。收到旧流程已复核的新稿与窗口时才按新版本重排。
- 有界重试、后续独立审核、取消与版本保护由旧程序执行，不自发增加调用、不重开方向或提交媒体。用户只改局部时保持无关内容和可用素材。
