# 广告形式与创意交接

供 `strategy` 与 `direction_review` 共用。以下是主要表达方式和方向字段的共同含义；字段冻结、修订权限和合法输出由本轮 Schema 与程序合同规定。

## 主要表达方式

| `brief.ad_form` | 内容怎样兑现 |
| --- | --- |
| `brand_tvc`（产品展示广告，兼容旧内部标识） | 产品及其已知特点是视觉中心。可以用视觉概念、具体用途或功能演示，不强加人物冲突；光影、尺度、运动与空间关系本身可以表达价值 |
| `scene_story`（剧情／场景广告） | 商品的已知用途或特点参与人物处境、行动和变化。无关段子结束后才摆商品不足以成立，也不强制危机或反转 |
| `presenter_pitch`（人物讲解广告／口播） | 出镜人物主要面向观众解释或演示商品，使用 `character_dialogue` 和有效说话角色；有人工作但全用画外音蒙太奇不算。按已选 `speech_delivery` 可安排同一人物声音延续到商品特写，仍须建立可见说话者，保留单说话人边界 |
| `auto` | 保留用户授权推荐的状态，在每个方向 `reason` 说明采用的方法并实际兑现，不默认剧情、不扩成三类各三条 |

三类可以混合，仍须有主要方式；电影感是风格，不等于某一种结构。类型标签、人物出现或声音名称本身不能证明内容符合所选形式。

## 用途与视觉意图

新三方向的 `brief.creative_intent` 分开记录：

- `use_context`：产品供谁、在什么环境使用；没有资料可为空。用途环境不是成片必须出现的地点。
- `setting_requirement`：仅记录用户明确要求成片呈现的地点或环境，否则为空。给理发师在理发店用不等于广告必须在店里拍；作者自选场景也不是用户硬要求。
- `reference_intent`：实际取得的参考信息，或明确归属于用户描述的视觉意图。只有文件名、链接或未访问视频时，不虚构镜头，不声称已看或已拆解。
- `structure_preference`：用户或其明确采用的参考意图限制结构时，才填 `product_visual`、`world_intercut`、`lifestyle`；否则 `auto`。单说高级、电影感或 TVC 不足以锁定结构，缺少偏好不触发新问卷。

## 影片概念与产品价值

每个新方向的 `film_concept` 只有一组概念约定：

- `structure`：产品展示可用 `product_visual`、`world_intercut`、`lifestyle`；剧情和人物讲解分别为 `scene_action`、`presenter_explanation`。明确结构偏好须兑现，无偏好时可同结构或不同结构，不强制三种各一条。
- `key_visual`：具体核心画面及变化关系。写清对象与视觉关系如何变化，不能仅写高级光影或酷炫运镜。
- `memory_anchor`：观众应记住的一个产品认识或可辨认视觉记忆，不是泛用口号或转化承诺。
- `sound_role`：声音的信息或节奏任务，与 `production.speech_mode` 一致。纯产品不等于无人声；视觉难以准确表达功能时可用短旁白补充已知意义，无需话语时可无人声。这里不写完整台词或动作解说。

`angle` 写主打特点，`audience_value` 写受众为何在意，`product_expression` 说明哪段实际内容让该特点被理解；均遵守 [商品依据](product-evidence.md)。`story_summary` 保留历史键名，承担唯一的简短创意展开，不要求三类都写成故事；`hook/development/payoff` 分记同一创意的进入、展开和落点，`attraction_mechanism` 说明具体观看期待，不另起一套稿。

## 选择与历史兼容

新候选完整填写上述字段；普通局部修订保留既有核心与对应关系，只按用户要求及本轮修订权限更新。旧记录原本缺少的新字段不强补，不改写历史，不因此重开选择。选定后交接创作意图、影片概念、产品价值和制作决定，具体时长与台词仍由后续落实；不能把选方向当成逐字逐秒审定。

作者写入 `brief.assumptions` 的初稿声音、人物或场景设想不等于用户硬要求；审核后实际制作安排以审后选中的 `production`、`film_concept` 为准，同时保留用户明确限制。

本文为映作的阶段合同。产品世界、品牌语境及视觉转化的方法借鉴范围由对应 Skill 的 `source_refs` 记录，不引入来源项目的完整制作流程或模型能力断言。
