# 广告形式与创意交接

供 `strategy` 与 `direction_review` 共用。以下是主要表达方式和方向字段的共同含义；字段冻结、修订权限和合法输出由本轮 Schema 与程序合同规定。

## 主要表达方式

| `brief.ad_form` | 内容怎样兑现 |
| --- | --- |
| `brand_tvc`（产品展示广告，兼容旧内部标识） | 产品及其已知特点是视觉中心。可以用视觉概念、具体用途或功能演示，不强加人物冲突；光影、尺度、运动与空间关系本身可以表达价值 |
| `scene_story`（剧情／场景广告） | 商品的已知用途或特点参与人物处境、行动和变化。无关段子结束后才摆商品不足以成立，也不强制危机或反转 |
| `presenter_pitch`（人物讲解广告／口播） | 出镜人物主要面向观众解释或演示商品，使用 `character_dialogue` 和有效说话角色；有人工作但全用画外音蒙太奇不算。按已选 `speech_delivery` 可安排同一人物声音延续到商品特写，仍须建立可见说话者，保留单说话人边界 |
| `auto` | 保留用户授权推荐的状态，在每个方向 `reason` 说明采用的方法并实际兑现，不默认剧情、不扩成三类各三条 |

三类可以混合，仍须有主要方式；电影感是风格，不等于某一种结构。类型标签、人物出现或声音名称本身不能证明内容符合所选形式。具体开场、可缩放节拍、台词、镜头和收束见本轮注入的类型 playbook。用户授权推荐时，方向选定前只注入短索引。

## 用途与视觉意图

新三方向的 `brief.creative_intent` 分开记录：

- `use_context`：产品供谁、在什么环境使用；没有资料可为空。用途环境不是成片必须出现的地点。
- `setting_requirement`：仅记录用户明确要求成片呈现的地点或环境，否则为空。给理发师在理发店用不等于广告必须在店里拍；作者自选场景也不是用户硬要求。
- `reference_intent`：实际取得的参考信息，或明确归属于用户描述的视觉意图。只有文件名、链接或未访问视频时，不虚构镜头，不声称已看或已拆解。
- `structure_preference`：用户或其明确采用的参考意图限制结构时，才填 `product_visual`、`world_intercut`、`lifestyle`；否则 `auto`。单说高级、电影感或 TVC 不足以锁定结构，缺少偏好不触发新问卷。

## 影片概念与产品价值

每个新方向的 `film_concept` 只有一组概念约定：

- `structure`：产品展示可用 `product_visual`、`world_intercut`、`lifestyle`；剧情和人物讲解分别为 `scene_action`、`presenter_explanation`。明确结构偏好须兑现。没有锁定时，产品片不能三条都用同一种结构；锁定后可以三条都在该结构里。不因此给商家增加画面骨架选择题。
- `visual_skeleton`：导演层怎么讲画面，`product_visual` 拆解、`world_intercut` 穿梭、`lifestyle` 生活。商家不选。人物讲解用生活，画面以人和商品特写为主。产品片在未锁定时可以是拆解、穿梭或生活，并和 `structure` 一致。商家没有锁定不出镜时，生活路径可以走到真人结果。剧情默认生活，三条里最多一条轻穿梭。生活不是平铺的真场景演示。
- `visual_motif`：贯穿母题，一个元素，不超过 16 字。
- `side_proof`：侧面证明，不超过 40 字。用场景、过程或概念层比喻看见好处，不写规格或数字。有已知好处时，默认工艺是生活里的问题、一小段和母题绑在一起的产品世界可视化、真实结果、产品定格。真场景演示不是创意标准，只在生成失败或缺少素材时兜底。
- 三个新方向必须在结构或骨架、母题、侧面证明上彼此不同。同一背景只换口号不算三个方向。
- `key_visual`：中段，不超过 40 字。剧情写转折，人物讲解写演示，产品展示写产品高光。写具体动作，不能只写高级光影或酷炫运镜。
- `memory_anchor`、`sound_role`：新方向不写。旧记录里若已有，修订时保留，不要删空，也不要为新卡片补写。声音形式看 `production.speech_mode`。

`label` 是商家扫一眼能选的短标题，2 到 8 个字，像「影棚特写」「早上赶出门」「工艺感」。`product_expression` 是核心创意，不超过 60 字，用大白话写出这条和另外两条差在哪。`consumer_insight` 是洞察，不超过 40 字，写成观众心里的一句话，说明为什么在意，不写他们正在做什么；这是创意假设，不是调研。`hook` 是 0–3 秒，`payoff` 是结尾，各不超过 40 字，大白话写这一下和另外两条有什么不同。`reason` 是为什么吸引人，不超过 40 字，说明为什么会被吸引、停下来并记住，不承诺转化。剧情三条的故事核要分开，不能都是同一个处境换说法。这些短句不写摄影散文。`hook_type` 用当前类型 playbook 里的具名开场编号，`brand_world` 只在概念层标功能环境、身份态度或感官仪式，不是商品事实。这些短句用观众能说的话。`big_idea`、`audience_value`、`story_summary`、`attraction_mechanism`、`angle`、`development` 是历史字段：新方向不写；旧记录保留原文字，修订时不要删空。情绪走向、视觉调性和分镜留给脚本。

## 选择与历史兼容

新候选只填上面的短句、结构、制作决定和编号。普通局部修订保留既有核心与对应关系，只按用户要求及本轮修订权限更新。旧记录原本缺少的字段不强补，已有长文不删空，不因此重开选择。选定后交接核心创意、洞察、三段和制作决定；情绪走向、视觉调性和分镜由后续脚本落实。不能把选方向当成逐字逐秒审定。

作者写入 `brief.assumptions` 的初稿声音、人物或场景设想不等于用户硬要求；审核后实际制作安排以审后选中的 `production`、`film_concept` 为准，同时保留用户明确限制。

本文为映作的阶段合同。产品世界、品牌语境及视觉转化的方法借鉴范围由对应 Skill 的 `source_refs` 记录，不引入来源项目的完整制作流程或模型能力断言。
