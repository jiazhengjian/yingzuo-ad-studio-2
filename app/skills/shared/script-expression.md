# 分类脚本与声音表达

供内容稿、分镜协调、局部修订与综合审核共同使用。沿已选方向组织观众实际看见和听见的内容。分类与概念字段由 `ad-form-contract.md` 维护；事实、声音能力、输出和流程仍服从各自合同。

## 输入各自约束什么

- **商品事实与用户要求**：以带来源的事实和用户明确要求为准，保留原有条件与程度。商家明确提供的功能可以直接表达；愿望、提问和作者设想不自动成为功能。未知原理或参数不能用来补造效果，也不自动否定已明确的主张，例如确认可折叠就可这样说，但不补折后尺寸。只有用户明确固定的台词原句要求逐字保留；声音身份与角色沿选定 `production`。
- **已选创意**：保留结构、核心画面或行动、观众处境、一句话概念、开场钩子、必要商品信息及落点。选方向是选其含义，不等于固定摘要的用词。台词可以化用处境和那一句话，按说话对象重新成句；不要念规则名、`reason`、`production_notes`，也不要把关注、呈现、兼顾、打造这类策划说法说给观众。未经用户固定的草稿台词仍可改写。
- **作者解释**：`brief.assumptions`、历史稿的目的说明与自评供理解来源，不高于明确事实和用户要求。发生冲突时保留已确认内容，调整作者解释。本轮 Schema 要求的 `purpose`、`message` 与方案摘要在实际画面、台词形成后概括它们，不能反过来把制作人员的话念给观众；`draft_format=content_only` 不输出这些解释。

## 沿已选方法展开

开场钩子、节拍形状、台词密度、景别和收束以本轮注入的类型 playbook 为准，并按 10–60 秒缩放。没有注入 playbook 时，沿下面的类型说明展开。

### 产品展示：组织一次有意义的观看

从已选 `key_visual` 中找出要展开的具体关系：某种外形怎样被认出、已知特点怎样显现，或产品与空间、使用者怎样关联。将它写成可发生的观看过程，明确上一画面留下什么期待，下一画面怎样展开、对照或兑现。景别、构图、光影、主体运动和摄影机运动是表达手段；依次看正面、侧面、全貌，不会自动形成新的产品认识。选定概要列出的部位与角度不是逐项锁定的镜头表，可在保留必要信息和核心视觉机制的前提下合并、重排。比如采用局部揭示时，要决定完整形象何时出现：早早展示全貌、后来反复正侧面，可能已消耗开场的期待；让局部线索逐渐组成整体，可以在同一揭示中容纳需要辨认的细节。此例只适用于相应核心，不把所有广告都改成悬念揭示。

保留所选结构：`product_visual` 用产品自身的形态、光影、尺度和运动关系推进；`world_intercut` 让产品与相关意象通过具体形状、动势或主题相连；`lifestyle` 在生活环境中呈现人与产品的关系，不强改短剧。视觉隐喻表达感受与联想，不冒充未知内部结构或功能实测。没有原理资料，也可以围绕可靠外观组织视觉概念，无须退回部位清单。隐喻留在方向里；写入镜头 `description`、`camera_move` 和视频提示词时，改成光线、材质、位置和动作。

先给主要视觉关系充分的观看时间，再用最合适的声音或画面承接必要支撑信息。允许一段静默、持续展示同一特点，也允许节奏对比；不按每拍一个卖点分配内容。结尾兑现已经建立的期待、完成动作或收束视觉关系，让产品记忆落在具体画面上；不自动再转回正面，也不追加独立文字卡。

### 剧情／场景：让产品参与人物的选择与变化

拍清人物为何行动、产品怎样参与、之后留下什么变化。一个小决定、一次分享或使用关系的完成即可，不强套危机、反转或三幕。去掉产品仍能原样讲完、只在最后摆包装的段子，需要重组。

对白服务当下人物关系；旁白可补前因、时间、动机或形成评述；无人声靠动作和状态承接。服从已选声音方式。压缩保留关键因果，必要过程用清楚的时间省略连接。

### 人物讲解：围绕观众需要理解的问题组织

明确讲述者向观众解释什么，让产品依据、相关演示与话语共同回答。可以介绍设计、解释用途、展示操作或回应顾虑，不机械套“痛点—夸赞—下单”。

人物实际面向观众讲解，不能仅在场景中工作、由另一个旁白解说。商品特写可以补依据，沿用既定说话人及其可见与画外延续约定；切到商品不等于换人。停顿让观众看清，不为填满时长逐项报功能。

混合手法时仍沿已选主要方式推进。`auto` 沿选中方向的实际方法展开，不能因缺少类型标签一律写成剧情。

## 画面与实际话语一起成稿

在同一内容段落中写实际画面与 `narration`，安静时留空；不能只交“旁白介绍功能”。先明确谁对谁说、听者此刻要理解什么，再写实际句子。产品旁白直接传达特点、选择理由或态度；场内对白完成邀请、回应或选择；人物讲解向观众解释问题。可以混合话语任务，不固定句式，也不要求每句话都增加卖点。

把台词单独连读一遍：听者没看过策划案，也应明白这句话的对象和意思。再放回画面，核对它增加了什么理解、关系或强调。广告短句、自然对白与完整讲解各有节奏，不为形式上的整句补抽象名词，也不以字数少自动代表高级。解释句子“想达到什么”不能替代真正写出那句话；未固定的表达应在本稿直接修改。用现有字段交接，不另写分析稿。

产品展示少说，指给观众看，落在能感觉到的边上、声音或光上。剧情让人物当场说，有来有回。人物讲解对着镜头，第一句就是钩子，带一个资料里已经有的具体好处。可以化用 `big_idea` 的意思，不要把关注、呈现、兼顾、打造、采用某技术、高端质感、赋能念出来。最、第一、根治、国家级、绝对、永久仍然不能出现。好坏对照见台词示例，那是方法，不是本商品的事实。

## 允许有作用的同述，避免无用的动作播报

暂时删掉一句，若商品理解、操作指引、人物关系或有意节奏均无损失，就精简或留白；必要信息须在整片保留。看得见的东西仍可以说，关键是它在此刻的作用：

- **教学：** 已知商品确有挂扣，演示连接时说“把挂扣扣在包带上”，能帮助观众完成操作。动作同步正是它的用途。
- **强调与揭示：** 在揭示时点明一个已知特点，使观众注意它，可以同述；随后是否继续说，应由信息任务决定，不能全片循环清点颜色、部位和角度。
- **喜剧与反差：** 人物说“这回我只拿一样”，画面中他犹豫地伸向第二样，可形成可理解的反差。矛盾发生在人物意图和行动之间，不授权画面违反商品状态或凭空证明性能。

这些是判断例子，不是必加桥段。审核实际句子、画面与时机；既不因出现动作词判失败，也不因作者标注“强调”就放行。

## 各阶段怎样使用

- 内容稿在 `visual_role` 与 `narration` 写实际表达。`draft_format=content_only` 只交实际内容与事实引用；完整内容稿的 `purpose/message` 只交接意图。分镜协调未固定的画面、原句与时间，使它们共同兑现。
- 综合审核检查实际原句、镜头顺序和结尾落点。概念摘要、依据 ID 与自评不替代成稿；不要求每镜一个新卖点或一句话。类型 playbook 里的节拍按片长缩放，不是把 15 秒模板原样重复，也不把类型偏差当成硬失败。

本文件是映作对现有已登记方法与实际问题的本地整理。三种产品影片结构的方法来源为 `tvc-director-main/references/treatment.md`。类型 playbook 另改编了时长模板、产品出镜、镜头词汇和阶段结构，中文台词例子由映作编写。导演落实方法的来源为 TVC AI Director，具体改编范围见注册表及来源声明。
