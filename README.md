# 映作 Ad Studio

面向国内实物电商商家的本地 AI 广告制作工作台。通过对话确认需求，依据商品事实选择广告思路，再编排镜头、检查图片并生成带中文原声的视频。当前是 **本地单用户原型的开源准备版本**，已接入商品策略、内容稿、分镜协调和独立的最终方案综合审核。

## 当前能做什么

- 上传商品图，选择 10–60 秒时长，进行动态澄清、方案确认与对话改稿；新方案修改旁白时同步调整画面和时间。
- 根据已知商品资料与本地规则给出 **3 个创意方向**，推荐项也由用户选择；候选先经独立方向审核，选择后只展开一套内容稿，在分镜中协调台词和动作，再独立综合审核实际最终内容与声画。新链路按阶段加载正式的 `Ads Video` Skills，保存实际版本与内容哈希；旧 `ad_expression` 仅保留历史兼容。左侧创意摘要展示受众、场景及内容首尾的构想；较长的公开策划说明归入对应任务的折叠过程区。修改方案沿用底部输入框。折叠分镜展示画面与独立旁白时段；一句完整旁白可覆盖同一内容节拍的相邻镜头，旧方案保留原逐镜台词编辑。
- 直接复用商品原图，生成一张场景图，并为选中方向的每位角色准备一张组合四视图。方案里有湿到干这类看得见的状态变化时，再各出一张起始静帧和结果静帧。过程镜对齐起始，切之后的结果镜对齐结果，不在同一镜里跳到终点。统一检查图片后才提交视频生成。
- 左侧对话展示真实任务进度，右侧查看图片、视频、片段和历史版本；支持刷新恢复、取消与下载。
- 新方案使用视频模型的中文原声，按计划合成为 9:16、720×1280、24fps 的 MP4。
- 保存任务回执、项目版本和素材来源，受理状态不明确时停止自动重发。

[Skill 索引](docs/SKILL_INDEX.md)列出 12 份规范 Skill：10 份已接入运行，外部参考与成片质检两份已写好规范但尚待接入执行能力。策略规则来自本地整理的方法，不是实时案例检索或市场研究。来源检查可追溯商家摘录和原图引用，但不能证明商品说法真实、图片观察准确或广告有效。

当前没有人物口型种草、自动最佳切点、跨段连续性修复、外部案例检索或自动发布。新原声视频不自动加字幕或独立结尾文字。此前的真实 20 秒样片已验证生成与导出链路；本轮脚本与音画计划改动不代表成片质量已有改善，商品还原、中文发音、声音自然度和营销效果仍需验证。

## 环境与安装

需要 Python 3.10+、Node.js 20.19+。macOS 已实测；源码使用 POSIX `fcntl`，Linux 具备兼容基础但尚未实测，Windows 不直接支持。新原声路线不依赖系统 TTS；旧画外音项目依赖 macOS `say` 和中文 `Tingting` 语音。FFmpeg 由 Python 依赖提供。

在项目根目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
cd frontend
npm ci
npm run build
cd ..
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8787 --workers 1 --no-access-log
```

打开 <http://127.0.0.1:8787>。完成安装后，macOS 也可双击 `start.command` 启动。关闭终端会停止本地服务。

## 连接模型服务

打开 <http://127.0.0.1:8787/setup> 配置连接，或参考 `.env.example` 创建本地 `.env`。当前配置为 `PLANNER_PROVIDER=tudou`、`PLANNER_MODEL=gpt-6-sol`，`TUDOU_API_KEY` 同时用于文本策划和原有图片/视频生成，需要该密钥具备相应模型权限。设置页保存密钥后立即生效，不向前端回显；修改供应商或模型配置后重启服务。未配置新变量的旧安装仍使用 `DEEPSEEK_MODEL` 和 `DEEPSEEK_API_KEY`，不会暗中切换或回退供应商。

图片和制作需求会发给配置的外部服务，调用可能产生费用。策划先用 `strategy → direction_review` 两次请求提供候选，等待用户选择。默认在选择后执行 `ad_script → storyboard → plan_review` 三次请求。试验开关 `JOINT_PLANNING_ENABLED=true` 可跳过前置内容稿，同次写文案与分镜，再独立审核；无返修时为两次请求，但真实探针仍出现多次返修和失败，**尚未证明稳定提速，示例配置保持关闭**。普通修改另需一次 strategy 路由，旧适配器不受开关影响。失败和返修另计，不能用正常调用数代替实际等待时间。`CONTENT_DRAFT_ENABLED=true` 是默认关闭的另一项试验：保留三次请求，初稿只写实际台词和画面，分镜阶段统一编排动作与时间；joint 开启时优先使用联合路径。`SPEECH_DRAFT_ENABLED=true` 是默认关闭的产品画外音候选：只对产品展示广告中的 `product_visual + voiceover` 替换初稿为整段旁白，导演仍收到完整选定方向，正常仍三次请求；joint/content_draft 优先，其他形式沿旧路径。单次人工简报的文案改善尚未证明该自动路径质量通过，详见验证记录。`PLANNER_STORYBOARD_EFFORT` 只调整土豆 gpt-6-sol 新版分镜的推理档位；缺省 high，可选 low/medium/high，本地部署及示例采用 medium；这不是模型更换，也不是提速保证。`.env.example` 里另有一组默认注释掉的快速配置：可把写稿、分镜、审核和返修指到 DeepSeek，超时或 504 时显式回退一次，并可选流式输出、270 秒失败上限、一轮返修、差异返修和推荐方向的文字预生成。strategy 仍用主模型。不配置这些变量时行为与原来相同。图片和视频提交不使用这组文字路由。是否更快、文案是否变差，都要在本机真实请求上对比，仓库里的离线测试不能代替。

分镜可协调未被用户固定的草稿台词和动作，返回内容及镜头覆盖关系后由程序统一排时；综合审核一起检查实际最终内容、动作状态、人物和全部台词窗口。容量与内容问题合计最多两轮局部 `plan_refinement`，每轮有效调整后独立完整复审；无实际修改或同类问题未改善时提前停止。修正保留已确认要求，不叠加旧时轴返修，不新增用户确认。每轮对话保存逐请求检查点，短暂连接错误最多自动重试两次，空回复另有一次机会，默认整轮最多12次文本请求；进程重启不清零预算。已完成步骤复用保存结果，输入或规则变更会拒绝沿用。作品成果与本轮修改分别展示：已有成片始终可播放、下载，修改失败不会替换成片。正常流程没有通用“恢复任务”；仅临时请求重试耗尽后可明确重新尝试，内容或配置问题给出对应入口。旧适配器保留原四阶段协议和旧记录读取。调用数减少不代表真实耗时或成片质量已验证，具体范围见项目现状和验收记录。

台词没有每秒1.8字符的固定目标，也不固定20秒的句数或节拍数。未分类型时仍是每秒2.9字符的保守工程上限；产品展示、剧情／场景、人物讲解默认约每秒3.0、3.8、4.8字符，可用环境变量调整。标点和空白计数，待真实音频验证。一句话不跨独立生成请求。`AD_TAGLINE_ENABLED` 默认关闭：不写口号、不加结尾字卡。打开后只允许多一句不超过10字的收束口播，文字仍不进画面。新方案10–30秒在一次生成内安排多个镜头，31–60秒按完整表达边界分组，连续动作不拆开；旧方案继续使用原来的10秒请求与裁切。当前图片参考模型的单次上限为30秒，跨请求声线与实际转场仍需试听检查。

图片和视频另行提交。当前限制的是调用或提交次数，不是人民币费用封顶；已经被远程服务受理的任务，取消后仍可能计费。没有配置连接时显示缺失配置，不会用演示视频冒充生成结果。

本版只供本机使用，保持 `127.0.0.1` 和 **单 worker**。不要直接暴露到公网，也不要让两个进程同时使用同一份数据。

## 开发与检查

前端开发可在后端运行时，另开终端执行 `cd frontend`、`npm run dev`。Vite 将 `/api` 和 `/media` 转发至本机 8787 端口；连接设置仍从后端的 `/setup` 打开。

在不含生产 `.env` 的干净工作目录运行离线测试，使用临时数据目录，避免导入应用时初始化到已有项目数据：

```sh
AD_DATA_ROOT="$(mktemp -d)" .venv/bin/python -m pytest -q
node --test tests/frontend_*.mjs frontend/tests/*.test.mjs
cd frontend
npm run build
```

离线测试使用替身验证接口与流程，不能代替真实供应商出片或广告质量验收。当前验收范围及历史整理记录见[验证记录](docs/VALIDATION.md)。

## 目录与发布范围

`app/` 为后端，`frontend/` 为工作台，`tests/` 为测试，`docs/` 为公开文档；`scripts/` 与 `.github/` 放整理脚本和协作配置。

`.local/` 保存私有研究与样片，`data/` 保存本地数据库和媒体，`.env` 保存连接配置；它们均不纳入提交。备份时应一起保存数据库和媒体。现有数据包含本机绝对路径，换目录恢复需完成路径重定位，不能只复制数据库。公开示例后续使用已确认可公开的素材，不随代码发布当前私有样片。

项目许可证尚未确定，将在正式发布前完成选择及第三方许可整理。

公开源码的检查与导出方法见 [scripts/README.md](scripts/README.md)，发布范围见[开源准备说明](docs/OPEN_SOURCE.md)。不要将整个含私有数据的项目目录直接压缩上传。
